# Simple Timer Web Application

This is a basic timer web application built with HTML, CSS, and JavaScript.

## Features

*   Set a custom timer duration in minutes.
*   Start, Stop (Pause/Resume), and Reset the timer.
*   A bell sound will play when the timer reaches zero. (Requires internet connection for the bell sound).

## How to Use

1.  **Clone the repository or download the files.**
    *   If you have `index.html`, `style.css`, and `script.js` locally:
        *   Simply open the `index.html` file in your web browser.
2.  **Set Duration:**
    *   Enter the desired timer duration in minutes in the input field.
3.  **Controls:**
    *   **Start:** Begins or resumes the countdown.
    *   **Stop:** Pauses the countdown. The "Start" button will change to "Resume".
    *   **Reset:** Stops the timer and resets it to the initially set duration (or the default 5 minutes if no value was set).

## Files

*   `index.html`: The main HTML structure of the application.
*   `style.css`: Contains the CSS styles for the application.
*   `script.js`: Contains the JavaScript logic for the timer functionality.
*   The bell sound is loaded from an external URL, so an internet connection is required to hear it.
